1. Gambaran Umum Sistem

Womenspace adalah platform forum digital eksklusif yang dirancang khusus untuk perempuan. Platform ini mengintegrasikan teknologi Machine Learning untuk memverifikasi gender pengguna pada saat pendaftaran, memastikan bahwa hanya perempuan yang dapat mengakses komunitas ini.

🎯

Tujuan Utama

Menciptakan ruang aman digital bagi perempuan untuk berbagi, berdiskusi, dan terhubung tanpa khawatir akan gangguan dari luar komunitas.

🤖

Inovasi ML

Verifikasi gender otomatis menggunakan computer vision (OpenCV), reduksi dimensi (PCA), dan klasifikasi (XGBoost) dengan akurasi tinggi.

🔒

Keamanan

JWT authentication, bcrypt password hashing, anonymous posting, dan sistem notifikasi real-time untuk menjaga privasi pengguna.

📱

Aksesibilitas

Desain responsif mobile-first dengan bottom navbar adaptif — nyaman diakses dari HP maupun desktop.

3. Pipeline Machine Learning

3.1 Proses Training (Google Colab)

TahapDetail
DatasetUTKFace — ±20.000 foto wajah dengan label usia, gender, etnis
PreprocessingOpenCV grayscale → Haar Cascade crop wajah → resize 128×128 → flatten
AugmentasiHorizontal flip untuk memperbanyak data 2×
NormalisasiPixel values / 255.0 → range [0.0 – 1.0]
Reduksi DimensiPCA 1000 komponen dari 16.384 fitur
ModelXGBClassifier: 600 estimator, lr=0.03, max_depth=8, early_stopping=20
Split Data80% train / 20% test, stratified
Outputgender_model.pkl + pca_model.pkl

3.2 Proses Inferensi (saat registrasi)

Pipeline inferensi harus identik dengan pipeline training untuk hasil yang akurat:

→
🔍OpenCVGrayscale + equalizeHist
→
✂️Haar CascadeCrop wajah terbesar
→
📐Resize128 × 128 px
→
🔢Flatten + /25516.384 fitur
→
📊PCA→ 1000 komponen
→
🤖XGBoostPredict + proba

Penting — equalizeHist: Histogram equalization diterapkan sebelum deteksi wajah untuk normalisasi pencahayaan. Ini kritis agar model bekerja konsisten pada berbagai kondisi foto (gelap, terang, indoor, outdoor).

5. Flowchart Sistem

5.1 Alur Registrasi + Verifikasi ML

  1. User buka halaman register.html
  2. Step 1 — Isi username, email, password (validasi client-side)
  3. Step 2 — Upload foto wajah (JPG/PNG/WEBP)
  4. Frontend kirim foto ke POST /api/auth/verify-face
  5. Backend jalankan ML pipeline → deteksi wajah → klasifikasi gender
  6. Jika laki-laki → kembalikan error 403, tampilkan tombol "Ganti Foto"
  7. Jika perempuan → lanjut POST /api/auth/register
  8. Backend simpan user ke DB, generate JWT token
  9. Frontend tampilkan overlay sukses dengan countdown 5 detik
  10. Redirect ke home.html

5.2 Alur Login

  1. User masukkan username + password
  2. POST /api/auth/login → backend verify bcrypt hash
  3. Jika valid → return JWT token → simpan ke localStorage
  4. Semua request berikutnya sertakan Authorization: Bearer {token}
  5. Token expires setelah 12 jam → user diminta login ulang

5.3 Alur Posting

  1. User tulis konten di compose box (opsional: media, poll, mode anonim)
  2. Jika ada media → upload sebagai multipart/form-data
  3. Backend simpan post ke DB, file ke uploads/media/
  4. Post tampil di FYP semua user dan Following tab followers
  5. Interaksi (like/reply/repost/bookmark) → update DB + trigger notifikasi

5.4 Alur Verifikasi Gender (Detail ML)

# predict_gender() di app.py
img_bgr   = cv2.imread(image_path)
gray      = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2GRAY)
balanced  = cv2.equalizeHist(gray)          # normalisasi kontras
faces     = cascade.detectMultiScale(balanced)  # deteksi wajah
crop      = balanced[y:y+h, x:x+w]
resized   = cv2.resize(crop, (128, 128))
features  = resized.flatten().reshape(1,-1) / 255.0
pca_feats = pca_model.transform(features)     # 16384 → 1000
pred      = gender_model.predict(pca_feats)[0]  # 0=male, 1=female
proba     = gender_model.predict_proba(pca_feats)[0]

7. Fitur Aplikasi

🔐

Verifikasi Gender ML

XGBoost + PCA + OpenCV. Foto dianalisis real-time, perempuan → lanjut, laki-laki → ditolak.

📰

Feed FYP & Following

Dua tab feed: For You (semua postingan terbaru) dan Following (hanya akun yang diikuti).

🌸

Story 24 Jam

Upload foto/video yang expire otomatis. Dikelompokkan per username seperti Instagram.

📊

Poll Interaktif

Buat voting di postingan, max 4 pilihan, hasil persentase real-time setelah vote.

👤

Mode Anonim

Post tanpa identitas. Channel khusus anonim terpisah. Post anonim tidak tampil di profil publik.

💬

DM + Reply Quote

Chat 1-on-1 dengan polling 3 detik. Klik bubble pesan untuk reply dengan quote.

🧠

Konsultasi Psikolog

Daftar psikolog dengan rating & spesialisasi. Chat langsung atau booking sesi terjadwal.

🔔

Notifikasi Real-time

Like, reply, follow, repost. Filter per kategori. Titik merah otomatis di navbar.

📌

Pin Postingan

Pin satu postingan di bagian atas profil. Klik ikon 📍 di postingan milik sendiri.

🔖

Bookmark

Simpan postingan ke koleksi pribadi. Akses dari halaman Tersimpan di navbar.

🔍

Explore & Trending

Pencarian postingan & akun. Trending berdasarkan likes dalam 7 hari terakhir.

📱

Responsive Mobile

Bottom navbar 5 item + "Lainnya" sheet. Dioptimasi untuk layar 360px hingga desktop.

8. Keamanan & Privasi

AspekImplementasi
PasswordBcrypt hashing via werkzeug.security
AutentikasiJWT dengan expiry 12 jam
OtorisasiSetiap endpoint protected dengan @jwt_required()
CORSAllow semua origin (development) — perlu dibatasi untuk production
File uploadValidasi extension whitelist (jpg/png/webp/mp4 dll), max 50MB
Postingan anonimAuthor disembunyikan dari API response jika is_anonymous=1
Profil privatPostingan anonim hanya tampil di profil sendiri, bukan publik
Cascade deleteHapus akun → hapus semua posts, likes, DM, notifikasi secara otomatis
Verifikasi perubahanEdit profil wajib konfirmasi password lama
⚠️ Catatan untuk production: Ganti JWT_SECRET_KEY dengan nilai acak yang kuat, batasi CORS hanya ke domain resmi, gunakan HTTPS, dan pertimbangkan migrasi ke PostgreSQL untuk skalabilitas.
